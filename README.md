# MusheeBridge: Mobile ARC

This is the Vercel-ready version of the MusheeBridge mobile app built from the Replit project.

MusheeBridge is a mobile-first bridge interface designed for moving USDC across supported testnet routes, with a clean Coinbase-style wallet experience and Mushee branding.

## Vercel deployment settings

Use the following settings when deploying the project to Vercel:

```text
Framework Preset: Vite
Install Command: npm install
Build Command: npm run build
Output Directory: dist
